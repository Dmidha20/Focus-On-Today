# Focus On Today

A simple productivity web application built with Vanilla JavaScript to practice core JavaScript concepts by building a real project from scratch.

## Features

- ✅ Add daily goals
- ✅ Mark goals as completed
- ✅ Dynamic progress bar
- ✅ Progress text updates automatically
- ✅ Data persistence using localStorage
- ✅ Input validation
- ✅ Custom checkbox with tick icon
- ✅ Responsive and clean UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## Concepts Practiced

- DOM Manipulation
- Event Listeners
- querySelector / querySelectorAll
- Event Handling
- classList
- Local Storage
- JSON.stringify()
- JSON.parse()
- Dynamic UI Updates
